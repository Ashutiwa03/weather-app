# 🌤️ Weather App

A simple and responsive Weather App built using React.js and Material UI.
Users can search for any city and get its current weather information.

🔗 **Live Demo:** [https://weather-app-hazel-two-38.vercel.app](https://weather-app-hazel-two-38.vercel.app)

## ✨ Features

- Search weather by city name
- Shows current temperature
- Shows humidity
- Shows minimum and maximum temperature
- Short weather description (cloudy, sunny, etc.)
- Fast and responsive UI
- Deployed on Vercel

## 🛠️ Tech Stack

- **React** (UI)

## 🚀 Getting Started

Follow these steps to run the project on your own computer.

### 1. Clone the repository

```bash
git clone https://github.com/Ashutiwa03/weather-app.git
cd weather-app
```

### 2. Install dependencies

```bash
npm install
```

### 3. Add your API key

Create a `.env` file in the project root and add:

```
VITE_WEATHER_API_KEY=your_api_key_here
```

Get a free API key from [OpenWeatherMap](https://openweathermap.org/api).

### 4. Start the development server

```bash
npm run dev
```

Open the local link shown in the terminal (usually `http://localhost:5173`).

---

## 📦 Build for Production

```bash
npm run build
```

The production files will be created in the `dist` folder.

---

## 🌐 Deployment

This project is deployed on **Vercel**. Every push to the `main` branch automatically updates the live site.

To deploy your own copy:

1. Push the code to GitHub
2. Import the repo on [vercel.com](https://vercel.com)
3. Add `VITE_WEATHER_API_KEY` in Environment Variables
4. Click **Deploy**
